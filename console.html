Predictive insights

Things the rule-based agents genuinely can't tell you on their own — patterns, not thresholds you already set.

This page is kept deliberately separate from the Agents page, on purpose: Agents shows what already happened and what your own rules say should happen next — retrospective and rule-based. This page is reserved for things a trained model finds that your rules can't produce by themselves, like a return-probability score or an early pattern nobody's rule was set up to catch.

Nothing here duplicates a number you can already see on Agents - if it's just a threshold restated, it doesn't belong on this page.

No predictive models built yet - the first candidate is customer return-probability, once there's enough history to train on reliably.

API push

If you have a POS, booking system, or custom app, it can push transactions directly - a live feed, no manual upload needed. Uses the same API key as the "API keys" page - generate one there first if you haven't.

curl -X POST https://wtapyfgtwkjyjrjdnhkb.supabase.co/functions/v1/mw-ingest \ -H "x-tenant-key: YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"action":"upload_transactions","rows":[{"mobile":"971501234567","date":"2026-08-11","amount":150,"external_id":"INV-1042"}]}'

Including external_id (your own invoice/order number) is optional but recommended if you also upload Excel exports of the same data - it prevents the same sale from being counted twice.
